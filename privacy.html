Privacy policy: Jarvis Analytics

Last updated 13 November 2026.

What it accesses. With the user's permission, Jarvis Analytics reads YouTube channel and video statistics (views, watch time, retention, traffic sources) through the YouTube Data API and the YouTube Analytics API, using read-only access.

How it's used. The data is used only to produce analytics reports for the owner's own channels and the channels they manage.

Where it's kept. Data is stored only on the owner's own computer. It is not sold, shared, or transferred to anyone else, and it is not used for advertising.

Google user data. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access. Access can be removed at any time at myaccount.google.com/permissions. Deleting the local files removes all stored data.
